# Plano de Implementação - Fase 04: Documentação para os Colegas

## 1. Visão Geral
Redigir documentação humanizada, acessível e visual para capacitar colegas de equipe a realizarem a contagem manual de 50 imagens de drones em máquinas Windows, mesmo sem experiência com Python ou ferramentas de IA.

## 2. Requisitos Técnicos
1. **`README.md` (Raiz):**
   - Apresentação clara do aplicativo e objetivo científico do projeto (Ground Truth para IA de contagem).
   - Guia de Início Rápido (3 passos: colocar imagem, clicar duas vezes em `iniciar_windows.bat`, marcar cabeças).
   - Tabela de comandos (Mouse, Teclado, HUD).
   - Orientações de envio de arquivos para consolidação.
2. **`docs/GUIA_DO_ANOTADOR.md`:**
   - Dicas práticas de anotação de multidões (critérios visuais para sombras, bordas, oclusões parciais).
   - Recomendações ergonômicas e boas práticas de checkpoint frequente (`Ctrl+S`).
3. **`docs/PROTOCOLO_ANOTACAO_50_IMGS.md`:**
   - Estratégia de distribuição das 50 imagens por lotes.
   - Checklist de controle de progresso e fluxo de entrega para o projeto principal.
